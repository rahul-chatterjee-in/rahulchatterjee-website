# Rahul Chatterjee - personal website (static build)

Zero-dependency static site: HTML + CSS + a few lines of vanilla JS. No build step,
no paid services. Open index.html in any browser, or drop the folder on any static
host. Content can later be ported to managed WordPress page by page.

## Pages
- index.html    Home - hero promise, EmoShift flagship, credibility stats, about strip, books strip, Sep 19 speaking band
- about.html    About - bio, career numbers, four topic lanes
- books.html    Books - EmoShift + Decoding Modern Day Managers (Amazon links), book 3 notify, bulk-order note
- blog.html     Bloggers Corner - 3 seed post slots (retention/first 90 days, frontline capability, L&D ROI)
- speaking.html Speaking & Workshops - Sep 19 HR SUCCESS TALK listing, topics, gallery, enquiry form (mailto, no backend)
- services.html  EmoShift at Work - umbrella services page: The Pressure, Priorities and People Lab flagship, EmoShift 90, Frontline Manager Excellence, From Hire to Inspire; pilot CTA by email, no fees published (approved by Rahul 2026-09-15)
- emoshift.html EmoShift framework - scaffold, grows when the framework content is ready
- contact.html  Contact - email + LinkedIn (no phone, per brief)

## Deploy options (all free until hosting is bought)
- GitHub Pages: push this folder to a repo, Settings > Pages > deploy from branch. Live URL in ~1 min.
- Netlify Drop / Cloudflare Pages: drag-and-drop the folder.
- Later: same content moves to managed WordPress (the plan) with these pages as the copy deck.
